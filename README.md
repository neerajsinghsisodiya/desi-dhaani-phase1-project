# Desi Dhaani — Phase 1 (Full Project Folder)

This is a complete, ready-to-push Laravel 11 project folder — not just app code.
Drag this whole folder into GitHub Desktop (or `git init` it yourself) and push;
`vendor/` and `node_modules/` are intentionally excluded (see `.gitignore`) since
those are never committed to any Laravel repo — you'll generate them locally in
step 2 below.

---

## 1. Push this to GitHub

**Using GitHub Desktop:**
1. File → Add Local Repository → select this folder.
2. If prompted "this doesn't appear to be a Git repository," click **create a repository**.
3. Commit all files (message: "Phase 1: catalog, cart, checkout, Razorpay payment").
4. Publish repository (or add your existing repo as the remote and push).

**Using the command line instead:**
```bash
git init
git add .
git commit -m "Phase 1: catalog, cart, checkout, Razorpay payment"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```
Use your own GitHub token/credentials when prompted — nothing here needs them baked in.

---

## 2. Get it running locally (after cloning/pulling)

```bash
composer install
npm install

cp .env.example .env
php artisan key:generate

# Auth scaffolding (login/register/logout routes + views) — Breeze isn't
# vendored here since it needs to run its own install step:
composer require laravel/breeze --dev
php artisan breeze:install blade
npm run build

# Database — edit .env with your DB_* credentials first
php artisan migrate
php artisan db:seed

php artisan serve
```

Visit `http://localhost:8000`.

---

## 3. Razorpay setup

1. Add Razorpay test-mode credentials to `.env` as `RAZORPAY_KEY_ID` and
   `RAZORPAY_KEY_SECRET`.
2. The checkout creates a Razorpay order on the server, opens Standard Web Checkout,
   and verifies the returned signature before marking the local order paid.
3. Test with Razorpay's test payment methods from the
   [Razorpay documentation](https://razorpay.com/docs/payments/payments/test-card-details/).

Stock only decreases after the server verifies the Razorpay payment signature —
never at "add to cart" or checkout submit. This prevents overselling.

## 4. What's already in this folder

- `app/Models/` — Product, Order, OrderItem, Address, User
- `app/Http/Controllers/` — ProductController, CartController, CheckoutController, RazorpayPaymentController
- `app/Services/RazorpayService.php` — Razorpay order creation + signature verification
- `database/migrations/` — framework tables (users, sessions, cache, jobs) + Phase 1 tables (products, addresses, orders, order_items)
- `database/seeders/` — sample ghee/oil products
- `resources/views/` — catalog, cart, checkout, success pages + a working layout
- `routes/web.php` — all Phase 1 routes
- Standard Laravel skeleton: `artisan`, `bootstrap/app.php`, `public/index.php`, `config/*.php`

later won't require touching this checkout code, since `seller_id` and
